# xszc 1.0.0

正式资产见 [xszc v1.0.0](https://github.com/isarmg/xszc/releases/tag/v1.0.0)。构建、运行与安装验收证据以该标签指向的精确源码和对应官方工作流为准。

## 变更

- 精确消费官方 xcsc 1.0.0，并同步 Rust、VERSION、Android / iOS 的软件版本。
- 软件基线、移动 JSON、数据库结构 revision 与 ABI 统一为 1.0.0 / 1；结构指纹与实例身份仍必须精确匹配。
- Rust / FFI 绑定与原生宿主一样核对 Server、账号和设备身份，禁止将旧队列绑定到另一设备；相同 UUID 大小写按标准身份比较。

公共客户端源固定为 `6fca4299f5c34a79db1c7bd4e889b418d2a58e2d`。软件补丁号独立于业务协议、持久状态与 FFI ABI。

业务协议源码固定为 `xszs@f5a2126f5008615f0fd6bd76e3e0378ee9600d54`；对应协议包与业务格式为 `1.0.0` / `v1`。公共发行工具固定为 `3441aa1e36861ae961371be3e0ce4636d649c6c1`。

## 验证与交付

各平台的编译、原生运行和安装生命周期由相应平台工作流验证。正式包的外部 SHA256 与包内完整清单绑定全部交付文件、运行依赖及原始许可证；公开版本的验证结果以对应 v1.0.0 Release 和最终源码工作流记录为准。
