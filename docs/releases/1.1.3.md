# xszc 1.1.3

## 本次变更

- 保留 1.1.2 中的图库选择、预览原图回退和 iOS 备份取消修复，不改变业务协议、持久状态身份或 FFI ABI。
- 精确依赖官方 xcsc 1.0.3，Git 修订 `5641a33e991209eecdbbc91cffaa3be545875757`，同步 Cargo.lock 与产品能力清单。
- 兼容 Android Build Tools 37 的 apksigner 证书输出。仍要求真实验签成功、单一签名者，以及所有签名方案证书的 SHA-256 指纹均符合既定正式证书；Source Stamp 证书不参与应用签名身份比较。
- 软件发行号统一为 1.1.3，Android versionCode 与 iOS build number 均为 1001003。已有 v1.1.2 标签不移动。

## 验证边界

本版本是发布候选。验签输出片段回归仅验证工作流解析，不能代替真实 APK 验签。之前提交的 CI 与原生平台结果也不能替代本候选最终提交的完整 CI、正式签名和资产验收；下载仍以实际成功发布的 Release 为准。
