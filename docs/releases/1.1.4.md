# xszc 1.1.4

## 本次变更

- Android 给其他媒体添加已有同名标签时复用标签，避免重复创建失败；两端按服务端精确名称匹配标签。
- Android 与 iOS 提示每项媒体最多 16 个标签，保留已有关联的幂等重试与移除入口；配套服务端负责最终数量校验。超限失败在当前预览中显示，保留重试输入。
- iOS 独立刷新可选相册筛选项，慢请求或失败不再拖住已经成功取得的图库页与下一页加载，失败时保留已知相册选项。
- 软件发行号统一为 1.1.4，Android versionCode 与 iOS build number 均为 1001004。依赖修订、移动状态合同、数据库 revision 与 FFI ABI 不变。

## 验证边界

这是尚未发布的候选。宿主 Kotlin/API 测试、Rust 与 C ABI 检查和源码绑定异步模型已完成；源码模型不是 Swift、URLSession 或原生界面测试。

新增 Android 标签 HTTP/预览错误回归与 iOS 标签 XCTest 已进入现有全量测试目标，仍须由最终提交的 Android/iOS CI 实际运行。正式签名 Android APK、未签名 iOS IPA 及 SHA256SUMS 继续使用既有发布流程；最终平台验收、签名与下载资产以该提交成功的工作流为准。
