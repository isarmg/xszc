# 安装、更新与卸载

当前源码候选版本 **1.1.5**。选择手机平台，安装、构建、日志、更新和卸载步骤分别保存在对应页面。

## Android

[Android 安装与构建](platforms/android.md)：Android 17/API 37+、arm64-v8a，使用正式签名 APK。

## iOS

[iOS 安装与构建](platforms/ios.md)：iOS 27.0+，发行 IPA 未签名，安装到真实设备前需要有效 Apple 签名与 provisioning。

### 从源码安装到设备

在 Mac 上构建与签名的完整步骤见 [iOS 实机安装](platforms/ios.md#从源码安装到设备)。

## 安装后

按[第一次备份](getting-started.md)完成登录、照片权限和小文件上传。两端共用的[设置](configuration.md)、[日常使用](usage.md)和[排障](troubleshooting.md)分别维护一份。
